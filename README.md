### Sobre

Desenvolvedor full-stack com foco em back-end .NET e front-end Angular. Minha experiência
vem do setor financeiro, trabalhando em plataformas de renda fixa: sistemas de alto volume,
com regras de negócio densas e forte exigência de rastreabilidade.

No dia a dia isso significou migrar módulos de um monolito para microsserviços, modelar
domínios com Clean Architecture e DDD, mapear esquemas Oracle legados com Entity Framework
Core e sustentar tudo com testes de unidade.

- Back-end: C#, .NET 8, ASP.NET Core, Entity Framework Core, Oracle
- Front-end: Angular com componentes standalone, signals e change detection OnPush
- Arquitetura: Clean Architecture, DDD, microsserviços, APIs REST
- Qualidade: xUnit, padrão AAA, análise estática com SonarQube
- Processo: Git, GitHub Actions, Docker, Scrum

---

### Como eu trabalho

Uso **Spec-Driven Development**: escrevo a especificação técnica antes de qualquer código e
só então uso IA como ferramenta de execução com escopo definido. Na prática, o documento de
investigação vem primeiro, a geração assistida vem depois, e a revisão é minha.

Ferramentas que uso nesse fluxo: GitHub Copilot, Claude e Cursor.

Isso reduz retrabalho e mantém as decisões de arquitetura sob controle humano —
a IA acelera a digitação, não substitui o desenho da solução.
